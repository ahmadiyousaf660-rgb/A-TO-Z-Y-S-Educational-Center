# A TO Z Educational Center

Full responsive language-learning web app.

Languages: English, Pashto, Dari (Persian), Arabic, Urdu, German.

Features: AI Teacher, AI Translator, Speaking Practice, Online Test + Percentage, Certificate Generator, responsive mobile/computer design, SY logo, secure server-side OpenAI key.

## Render
Build Command: `npm install`
Start Command: `npm start`
Environment Variable: `OPENAI_API_KEY` = your OpenAI secret key.

Never put the secret key in HTML/JS. Keep it in Render Environment Variables.
